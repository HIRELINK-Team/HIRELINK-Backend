# 채용공고 작성·상세·수정 연동

## 기존 API

- 새 공고·임시저장: `POST /api/job-postings`
- 작성 중인 공고 저장·모집 시작·공고 수정: `PATCH /api/job-postings/{jobPostingId}`
- 상세 조회·이전 공고 불러오기: `GET /api/job-postings/{jobPostingId}`
- 목록: `GET /api/employers/me/job-postings`. 상태 필터 생략 시 모집 중·마감 목록이며 임시저장은 제외한다. 현재는 페이지 없이 전체 목록이므로 화면의 전체·모집 중·마감 개수를 목록에서 계산할 수 있다.

임시저장은 사업장 ID와 DRAFT 상태로 생성하고, 이후에는 반환된 공고 ID로 PATCH한다.
이전 공고 불러오기는 상세 응답에서 작성 항목만 채운 뒤 새 공고를 POST한다. 기존 공고는 수정하지 않으며 날짜와 새 공고 상태를 다시 확인한다.

## 한국어 수준과 우대 경력

- `requiredKoreanLevel`: `BEGINNER`(초급), `INTERMEDIATE`(중급), `ADVANCED`(고급), `NONE`(무관).
- `NONE`은 요구 수준이 없다는 명시적 값이다. 모집 시작 시 필드 생략·null은 여전히 허용하지 않는다.
- 유학생 프로필의 한국어 수준 값은 변경하지 않는다. 지원자 상세에서 공고 요구 수준이 `NONE`이면 한국어 조건을 충족한 것으로 표시한다.
- 새 작성 화면에서는 `preferredExperience`를 전송하지 않는다. RECRUITING 생성 시 생략·null은 `NONE`(우대 없음)으로 저장한다.
- 미입력 임시저장은 null을 유지할 수 있고, 모집 시작 시 `NONE`으로 저장한다.
- 기존 클라이언트의 우대 경력 값과 기존 공고의 저장값은 호환을 위해 유지한다. PATCH 생략은 기존 값 유지이며 명시적 null은 기존처럼 거부한다. 기존 공고를 불러와 새로 작성할 때는 숨겨진 우대 경력을 복사하지 않는다.

## 근무시간

30분 단위의 기존 `workTimes` 계약을 사용한다. 주야간 전환·드래그·시간표 표시는 프론트가 처리한다.
월요일 22시부터 화요일 04시까지는 아래 두 구간으로 전송하고, 화면에서는 하나의 야간 근무로 묶어 표시할 수 있다.

```json
[
  { "dayOfWeek": "MON", "startTime": "22:00", "endTime": "00:00" },
  { "dayOfWeek": "TUE", "startTime": "00:00", "endTime": "04:00" }
]
```

종료 `00:00`은 해당 요일 끝이다. 일요일 야간은 일요일과 월요일로 나눈다. 주간 합계는 날짜별 구간의 길이를 합산한다. 동일 요일의 겹침·중복은 API가 거부한다.
`workTimeNegotiable`은 기존 계약대로 전송한다. 지원자별 허용 근무시간 판정은 공고 작성의 단순 합계 계산과 별개다.

## 환산 시급

작성·수정 중 입력값 옆의 미리보기는 프론트가 즉시 계산한다. 계산 전용 API를 추가하지 않는다.
저장 후에는 등록·수정·상세 응답에 추가된 `convertedHourlyWage`를 사용할 수 있다. 이 필드는 요청에 보내지 않으며 서버가 저장된 값으로 계산한다.

- HOURLY: 입력한 `wageAmount` 그대로.
- MONTHLY: `월급 / (주간 근무시간 × 4.345)`.
- 서버는 추천의 `WageScoreCalculator.hourlyWage`를 직접 재사용한다. 기존 추천 점수의 계산식과 정밀도는 유지한다.
- 내부 나눗셈은 소수점 10자리 HALF_UP, 표시용 응답만 원 단위 HALF_UP 반올림한 정수다. 프론트도 동일한 상수·반올림 기준을 사용한다.
- 월급이 없거나 월급의 근무시간이 없는 임시저장은 `convertedHourlyWage: null`이다. 프론트도 입력이 부족하면 환산 시급을 표시하지 않는다.
- 계산 결과는 DB에 별도 저장하지 않는다. 급여·근무시간 변경 후 응답에서 다시 계산한다.

| 월급 | 주간 근무시간 | 표시용 환산 시급 |
| --- | --- | --- |
| 1,000,000원 | 18시간 | 12,786원 |
| 869원 | 16시간 | 13원 (내부 계산 12.5원, 반올림 검증용) |

서버의 새 응답 필드 외에 목록·공고 마감 API 계약은 유지한다. 신규 DB 마이그레이션은 필요하지 않다.
